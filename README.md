
# Asin Anna Noble - Personal Portfolio

A personal portfolio website built using HTML, CSS, JavaScript,
Node.js, Express, and MongoDB.

## Features

- Personal introduction
- Education section
- Skills section
- Projects section
- Contact form
- MongoDB contact message storage
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Setup Instructions

1. Install Node.js and MongoDB.
2. Open the project folder in VS Code.
3. Run `npm install` in the terminal.
4. Create a `.env` file in the project root.
5. Add the following line to `.env`:

   `MONGODB_URI=mongodb://127.0.0.1:27017/asinPortfolio`

6. Start the server using `npm start`.
7. Open `http://localhost:3000` in your browser.
